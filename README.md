# oep-developer-guides

Developer guides and sample applications for the Open Edge Platform (OEP).

## Applications

### [License Plate Recognition](license-plate-recognition/)

Multi-stage inference pipeline for license plate detection and text
recognition using YOLOv11, PP-OCRv4, OpenVINO, and DL Streamer.

See the [application README](license-plate-recognition/README.md) for
setup and usage instructions.
