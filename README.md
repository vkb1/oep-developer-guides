# OEP Developer Guides

Developer guides and sample applications for the Open Edge Platform (OEP).

## Sample Applications

### [License Plate Recognition](sample-apps/license-plate-recognition/)

A progressive set of sample applications demonstrating license plate detection
and text recognition:

- **V1**: HuggingFace models (YOLOv11 + TrOCR) for baseline detection and OCR
- **V2**: OpenVINO IR optimized models with performance comparison
- **V3**: Intel DL Streamer pipeline for real-time video stream processing

See the [License Plate Recognition README](sample-apps/license-plate-recognition/README.md)
for detailed setup and usage instructions.
